# Sistema de Gestión de Empleados

Proyecto académico de Introducción a la Programación 2 para administrar la información del personal de una empresa.

## Funciones principales

- Expedientes e historial laboral.
- Departamentos, puestos y horarios.
- Control de asistencia y permisos laborales.
- Nómina mensual y boletas de pago.
- Administración de usuarios y accesos.
- Reportes, constancias y exportación a PDF y Excel.
